# MEL POS releases

Windows installers and update files for **MEL POS** (MEL Point of Sale), the retail point of sale by
MEL Business Solutions, Malaysia. The source code is not in this repository.

Each release has:

- `MELPOS-x.y.z.exe`: the Windows installer.
- `latest.json`: read by MEL POS to offer the new version in the app, with what's new.
- `SHA256SUMS.txt`: checksums of the files.

MEL POS installs an update only if it is signed by MEL Business Solutions. MEL POS needs a License code from
MEL Business Solutions; without one it runs in Demo mode.
